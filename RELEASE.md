## MVP Complete — From Idea to Deployed Product

This release marks the **full MVP** of the **X Post Creator & Scheduler** — a **local-first, TDD-driven, CI-enforced** web app that lets any X user:

- Generate engaging posts with an LLM
- Edit, preview, and attach images
- Drag-and-drop to organize
- Schedule exact release times
- Auto-post with retry
- View history + manual retry

**All in <60 seconds.**
